# Ajker News - Modern News Portal Solution

Ajker News is a professional-grade, high-performance News Portal application. This project is built using a decoupled architecture where **Laravel 12** handles the robust API backend and **Vue.js 3** provides a fast, interactive Single Page Application (SPA) experience.

## Key Features

- **Decoupled Architecture:** Laravel API-driven backend.
- **Modern UI:** Built with Tailwind CSS v4 for a clean and professional look.
- **Dynamic Slider:** Integrated Swiper.js for featured news.
- **Responsive Design:** Fully compatible with Mobile, Tablet, and Desktop.
- **Advanced Admin Panel:** Professional dashboard for news and category management.
- **SEO Optimized:** Clean URL slugs and professional Bengali typography (Kalpurush/Noto Serif).
- **Tabbed Content:** Real-time switching between Latest and Popular news.

## Tech Stack

**Backend:**
- Framework: Laravel 12 (Latest)
- Database: MySQL
- Authentication: Laravel Sanctum

**Frontend:**
- Framework: Vue.js 3 (Composition API)
- Styling: Tailwind CSS v4
- Router: Vue Router 4
- State Management: Pinia (Planned)
- Components: Swiper.js, FontAwesome
